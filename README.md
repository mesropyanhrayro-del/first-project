# Python story generator(Mad Libs)
This project is a simple interactive storytelling program written in Python. 
It allows users to choose from templates  any and fill in words to generate a fun, 
personalized story. If the user enters an invalid choice,
the program randomly selects a template to keep the game moving.

## Features
1. The program asks the user to choose a template (1, 2, or 3).
2. If the input is invalid, a random template is selected automatically.
3. Based on the chosen template, the program prompts the user for different words (numbers, nouns, adjectives, verbs, etc.).
4. Once all inputs are collected, the program prints out a complete story using the user’s words.

## Templates
1. **Hospital Story**
2. **Camping Story**
3. **Enchanted Castle Story**
